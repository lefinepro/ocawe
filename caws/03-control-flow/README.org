** 03 - Control Flow Example

*** Description

Demonstrates Crystal-native control flow in the Ocawe workflow DSL. Shows how to use =unless=, =if/elsif/else=, =parallel=, =while=, and =until= for dynamic agent orchestration.

*** Features

- =unless= - Skip preprocessing when =skip_preprocessing= is true
- =if/else= - Conditional agent selection (translator vs passthrough)
- =parallel= - Run validator and formatter concurrently
- Sequential execution for analyzer and finalizer

*** Control Flow Reference

| Directive | Behavior |
|-----------|----------|
| =unless= | Execute block when condition is false |
| =if/elsif/else= | Conditional branching |
| =parallel= | Execute agents concurrently |
| =while= | Loop while condition is true |
| =until= | Loop until condition is true |
