** 01 - Simple Codex Agent

*** Description

Minimal example demonstrating a single Codex coding agent. This is the starting point for understanding the Ocawe framework.

*** Features

- Single =agent "codex-agent"= node
- Default model configuration with =@[Model("cliproxy")]=
- Memory-based data adapter
- Basic input/output schema validation

*** Structure

#+begin_src 
01-simple-codex/
├── Cawfile              # Root configuration
├── agents/
│   └── codex-agent.md   # Agent definition with schema
└── README.md
#+end_src

*** Running Locally

#+begin_src bash
# From the caws/01-simple-codex directory
ocawe up

# Or specify explicit path from project root
ocawe up caws/01-simple-codex

# Run in background (detached)
ocawe up -d caws/01-simple-codex

# Override port
ocawe up --port 8080 caws/01-simple-codex
#+end_src

*** Testing

#+begin_src bash
# Execute workflow
curl -X POST http://localhost:4111/v1/workflows/01-simple-codex/runs \
  -H "Content-Type: application/json" \
  -d '{"input": {"task": "Write a hello world in Python"}}'
#+end_src
