** 09 - Custom Agent (Binary)

*** Description

Demonstrates how to write a custom agent that calls an external binary. This is the recommended way to add agents — as executable commands with their own model configuration.

*** How It Works

1. Define the agent in a markdown file with =model:= frontmatter
2. The agent calls an external binary (e.g., =opencode=, =claude=)
3. Pass the task through stdin/stdout
4. Handle API keys via environment variables

*** Installing Agent Binaries

#+begin_src bash

npm install -g @anthropic/opencode

# Or clone and build
git clone https://github.com/nicepkg/opencode

*** Example: Writing Your Own Agent

Create an agent markdown file (=agents/my-coder.md=):

#+begin_src yaml
---
name: "My Coder"
description: "Custom agent"
model: "openai/gpt-4.1-mini"
---

You are a helpful assistant.
#+end_src

Create a binary wrapper (=bin/call-coder.sh=):

#+begin_src bash
#!/usr/bin/env bash
set -euo pipefail
MODEL="${MODEL:-openai/gpt-4.1-mini}"
API_KEY="${OPENAI_API_KEY}"
TASK="$1"

# Call external binary with task
response=$(opencode --model "$MODEL" --key "$API_KEY" "$TASK")
echo "$response"
#+end_src

*** Key Points

- Agent definitions go in =agents/*.md=
- Model is specified in frontmatter (=model: "provider/model"=)
- External binaries are called by the agent framework
- API keys are passed via environment variables
- Use =@[Model("openai/gpt-4.1-mini")]= and =@[Validate]= in Cawfile to set the workflow contract
