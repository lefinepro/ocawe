** 02 - Multi-Agent Workflow

*** Description

Demonstrates multiple agents working together in a sequential pipeline. Shows how to combine different agent types (workflow orchestrator, opencode, main) for complex tasks.

*** Features

- Sequential agent pipeline
- Multiple custom agents: =agent "workflow-agent"=, =agent "opencode-agent"=, =agent "main-agent"=
- Input/output schema validation with =schema_ref=
- Type-safe workflow contract with =WorkflowInput=/=WorkflowOutput= structs and =@[Validate]=

*** Structure

#+begin_src 
02-multi-agent/
├── Cawfile                   # Multi-agent configuration
├── agents/

#+end_src

*** Configuration Notes

- Each agent in the pipeline receives output from the previous agent
- The =workflow-agent= orchestrates task distribution
- Custom agents defined via markdown files with model frontmatter
- Use =@[Model("openai/gpt-4.1-mini")]= to set default model for the workflow
- Keep workflow-level schemas permissive on output metadata with =strict: false=
