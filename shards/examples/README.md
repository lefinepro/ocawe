# Cogni Examples

Examples are stored under `shards/cogni/shards/examples` and are not loaded by default runtime settings.

Included examples:
- `agents-example`
- `skills-example`
- `workflow-example`
- `voice-playground`
- `rag-playground`
- `simple-model-test`

Each bundle follows `.acd.cr` conventions with optional `agents/`, `skills/`, and `tools/`.
